유튜브 다국어 제목·본문 번역 + 자동 등록

유튜브 제목과 본문(설명글)을 100개국 언어로 번역하고, 끝나면 내 채널 영상에 자동 등록

1 설정

채널관리
채널추가
채널을 누르면 그 채널로 등록합니다. '연결'은 1시간마다 한 번씩 필요할 수 있습니다(구글 보안 규칙).
여러 유튜브 채널을 등록해 두고 골라서 쓸 수 있습니다.
① 아래 버튼을 누르면 구글 로그인 창이 뜹니다.
② 채널이 있는 구글 계정을 고르세요. 한 계정에 채널이 여러 개(브랜드 계정)면 채널 선택 화면에서 원하는 채널을 고르세요.
③ 허용을 누르면 채널관리 목록에 추가되고 바로 선택됩니다.
2단계에 구글 Client ID가 먼저 입력되어 있어야 합니다. 채널 정보는 이 브라우저에만 저장됩니다.
선택한 채널의 영상 주소를 넣으세요. 공개·일부 공개·비공개·예약 영상 모두 가능합니다.
제목을 바꾸고 싶으면 여기서 고친 뒤 번역하세요. 고친 제목이 원본 제목으로도 함께 등록됩니다.
본문은 제목과 같이 번역되어 각 언어 설명으로 등록됩니다. 해시태그(#)만 있는 줄과 링크는 번역하지 않고 그대로 둡니다. 비워두면 원래 설명이 유지됩니다.

유튜브 주소 모드 + 채널 연동(2단계)이 되어 있어야 작동합니다. 연동이 안 돼 있으면 번역 시작 시 구글 로그인 창이 뜹니다.
▸ 고급 설정 (번역 한도 늘리기)
무료 번역 엔진은 하루 사용량 제한이 있습니다. 이메일을 넣으면 한도가 늘어납니다. 100개국 + 본문은 사용량이 많으니 이메일 입력을 권장합니다.
